StrataOS 0.1

This page comes from httpd, a program in Strata assembly running under StrataOS on an emulated Strata machine: a 64-bit ISA where memory is explicit I/O, every tier is visible to software, and writable memory has exactly one owner at a time.

The machine

  • Core 0 runs only the kernel. Files, the console, pipes, processes, devices and TCP/IP are servers: user processes that get requests as lent 4 KiB message buffers. Nothing is copied between address spaces, because there are none.
  • Programs share the worker cores, switched every 2 ms. A switch copies out the part of the Local Store a program uses: the cost other machines hide. See what the machine is doing.
  • This request went through the network server net (IPv4, TCP, UDP: its programs) and the file server fs, which reads the disk from user mode.

Files have tags, not directories

A file has one name and any number of tags. A URL path is a set of tags: /src/demo/ lists the files tagged both src and demo, and /src/demo/hello.s is hello.s, if it carries both. -tag leaves a tag out: /src/-demo/.

  • every file
  • /bin/ programs
  • /sys/ the servers
  • /src/ sources, assembled on the machine by as
  • /src/demo/ the bare-metal examples
  • /forth/ Strata Forth
  • /doc/ and /etc/
  • /www/ this site

Some sources

  • hello.s: the first example, every line commented
  • sh.s: the shell, with the program library appended
  • as.s: the assembler, written in Strata assembly
  • core.fs: the Forth that Strata Forth builds on
  • motd, rc

Try

strata$ httpd &          # this server (port 80; -p PORT)
strata$ ls /www           # its files: index.html, style.css
strata$ echo hi > /www/note.txt   # a new page, at /www/note.txt
