    About this debugger
    
    
      
      
    • In the browser, the program runs in a Web Worker under the same engine as
        strata-dbg, with the virtual timer and the reference one-instruction-per-core
        interleaving: the run is deterministic, so every tick of it can be revisited (the slider, the ◀
        buttons). The engine keeps a snapshot every so many ticks and re-executes from the nearest one.
      • 
      
    • On your machine: build/strata-emu -c 4 -j -T virtual --debug 4455 build/examples/pipeline.stx
        and open http://localhost:4455/debug/: the page connects to that engine instead
        (or ?ws=host:port from here). strata-dbg is the text front-end.
      • 
      
    • The reference emulator copies a memory transfer at the instant it issues, so its bars have no
        length; device reads that wait (console input, the timer's WAIT) stay in flight, and their tags
        stay busy, until the device completes them. Stalls are the rounds a core could not make its step.
      • 
      
    • Keys: c continue, Esc pause, s step, n next, f finish,
        r round, S / R / C the same backwards, [ ] the current core.
