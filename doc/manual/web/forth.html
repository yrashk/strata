A Forth for Strata, the ISA where memory is explicit I/O: a small kernel in Strata assembly and the rest of the language written in Forth, compiled at power-on, with words that compile to native code installed the only way code can reach the instruction Local Store. Every word the system defines is below, with its stack effect, what it does, where it lives and its source, read from lang/forth/ itself. The playground runs the real forth.stx in the WebAssembly emulator: press Try on any word.

OverviewWhat it is

A classic bootstrap: the kernel, forth.s, is the outer interpreter, a native-code compiler, the dictionary, number parsing, catch/throw, multicore support, the far cache and about 150 primitives (every line commented). core.fs builds the rest of the language on them: control structures, a small assembler, defining words, strings, number formatting, locals, quotations and the words for tiers, capabilities and cores. tools.fs and see.fs add words, dump, the capability and JIT inspectors, and a disassembler with see.

It runs bare metal on strata-emu and strata-rtl (8 cores by default, byte-identical console output on both), and as a program of StrataOS 0.1: forth at the shell, forth FILE, pipes, -n N forth for threads. One kernel source, two platform layers (lang/forth/bare/, lang/forth/os/).

Threading model: native code, installed by transfers

Subroutine threading, compiled to machine code. A colon definition is a routine: a prologue that saves ra, one jal per word called or the word's body copied inline, and an epilogue. Stores cannot reach the I-LS, so the compiler assembles a definition into a 4 KiB staging buffer in the D-LS, and ; installs it with two transfers: a tput to a far-memory mirror of the I-LS (far offset = I-LS address), then a tgetx from the mirror into the I-LS. A fetch from a range a tgetx is still filling waits, so the word can run at once. Everything compiled can be read back from the mirror: see disassembles it, the compiler inlines from it, other cores install it from there.

RegisterUse
s1the top of the data stack, cached
s0the data stack pointer: it points at the second item and grows down
spthe return stack, which is the machine stack
s2, s3the index and limit of the innermost do loop (i is mv s1, s2)
s4the locals frame
t*, a*, s5..s11scratch: any word may clobber them

The compiler inlines primitives of at most four instructions ({{inline}} of them are marked inline), folds a 16-bit literal followed by + - and or xor lshift rshift arshift @ ! c@ c! into one instruction (a variable then @ is one ld from an absolute address), turns a call just before ; into a jump (tail calls; recurse in tail position is a loop) and keeps do loop indices in registers. Under StrataOS, where code space is 32 KiB, compact code makes the prologue one jal t0, k_enter and a return one j k_exit.

Strata instructions name capability registers and transfer tags in immediate fields, so "transfer through capability register n" is sixteen instructions. xexec ( a0 a1 a2 insn -- a0' ) assembles the one wanted, installs it with a ret into one of eight I-LS trampolines (direct mapped by a hash, so a loop pays the install once) and calls it. Every capability and transfer word in core.fs is a one-liner over xexec.

Cores, capabilities and far memory

Other cores are workers. At power-on core 0 gives each a private 64 KiB page and a copy of the job board, an atomics-only segment. A worker waits in ctake: a capability with X permission is the image (core 0's c0, lent: it tgetxes the code and tgets a snapshot of the dictionary, then gives it back); anything else is the doorbell for a job on the board. spawn publishes a new image only when something was compiled since the last one. Memory moves between cores as ownership, with give and take.

far@ and far! address the heap capability through a 2-way, 32-set write-back cache of 64-byte lines in the D-LS, built on the hardware's ltag and linst; .fcache shows its hits, misses and write-backs.

The dialect

Close to Forth 2012 for the core words. Deviations:

  • A cell is 64 bits and there are no double-cell words; <# # #s #> work on single cells, */ has a 64-bit intermediate, um*hi gives the high half of a product.
  • / and mod truncate, like the hardware.
  • Code space and data space are separate: here, , and allot are data space; chere is the code pointer. String literals live in data space.
  • Numbers: $ff, #99, %1010, 'c', -$10. Names are case-blind.
  • Locals { a b -- } at the start of a definition (up to 16, to works on them); quotations [: ... ;]; [if] [else] [then] within one line.
  • bye, or the end of input, halts every core (StrataOS: ends the process). There is no Ctrl-C on bare metal: the REPL runs in supervisor mode, which nothing preempts.
  • Under StrataOS the tools ({{tools}} entry points: see, words, dump, ...) are not compiled at start-up: their file is loaded, run and forgotten when one is used; require tools / require see load them for good.

Reading the reference

Each entry gives the stack effect and description from the source's own comments, the kind of word (a kernel primitive, inlined or called; a colon definition; a constant, variable or created word), whether it is immediate, where it is available (everywhere unless marked: StrataOS only, bare metal only, loaded on demand under StrataOS, or after require), and its source, linked to its lines in the source browser. Link to a word as forth/#w-name, with symbols spelled out: #w-dup, #w-plus-store (+!), #w-dot-quote (.").

In the browserPlayground

The playground (the panel at the right; on narrower screens, the bar at the bottom of the window, which opens it) is the Strata reference emulator compiled to WebAssembly, running the real Strata Forth image (forth.stx, bare metal, 8 cores, a 640×400 framebuffer), the same as make forth on the desktop and the play page's Forth. Click the terminal and type; each line you enter is echoed and answered with ok. Try on a word types its example in (most come from the regression test, lang/forth/tests/test.fs; words it does not use show their machine code with see). The demo menu pastes one of lang/forth/demos/: gfx renders a Mandelbrot set on every worker core into the screen, which opens under the terminal when something is drawn. Reset boots a fresh machine.
