Stralog

A Prolog for Strata, written in Strata assembly and running as a StrataOS program. Strata's memory is explicit I/O, and Stralog's engine is built around that: every term lives in far memory, reached only by transfers, and the data Local Store holds windows onto the tops of its stacks and a small far cache. The playground runs StrataOS in the WebAssembly emulator with stralog started: press Try on an example.

OverviewWhat it is

ISO core Prolog in one namespace: cut, if-then-else and soft cut, negation, call/N, catch/throw with ISO error terms, assert/retract under the logical update view, findall/bagof/setof, DCGs, op/3, files, lambdas for maplist and its kin. Integers have 61 bits (an overflow is an evaluation_error); there are no floats, bignums or modules.

strata$ stralog
Stralog 0.1
?- X = f(Y), Y = 3.
X = f(3), Y = 3.
?- [family].
true.
?- ancestor(A, jim).
A = pat ;
A = tom ;
A = bob ;
false.
?- findall(D, ancestor(tom, D), Ds).
Ds = [bob,liz,ann,pat,jim].

The engine

The engine is a structure-copying interpreter in Strata assembly, every line commented.

  • Clauses are compiled once, when they are consulted or asserted, into templates in a clause store.
  • A call unifies the goal with the head's template, building only what it binds.
  • The body becomes a continuation term on the heap.
  • First-argument indexing keeps most deterministic calls from leaving a choicepoint.
  • Where the code lives: the solve loop, unification and the memory code are resident. The reader, the writer, arithmetic and the builtins are 4 KiB code units that StrataOS pages into the instruction Local Store when they are called.
  • Written in Prolog: the top level, consult, the list library, sorting, bagof and DCG translation are in boot.pl, which travels in the image and is consulted at start-up.

Memory is explicit

  • Cells: a cell refers to other cells by arena offset, never by Local Store address.
  • Windows: the heap, the trail and the choicepoint stack each have a window in the data Local Store over their top:
    • a push past a window's end writes its lower half out with an asynchronous tput, and nothing waits for it;
    • backtracking frees heap without any transfer, because everything above the restored top is dead;
    • the next push below the window slides it down, reading back at most one line.
  • The far cache: everything else goes through a 4 KiB write-back cache on the hardware's tag table (ltag/linst): older cells, the atoms, the clauses, the findall answers.
  • Garbage collection: a sliding mark-and-compact collector runs between goals, through the same paths. It tidies the trail first, so that entries left behind by cuts keep nothing alive.
  • What moved: statistics/0 shows it.

Running it

  • stralog opens the top level.
  • stralog FILE ... consults files first.
  • stralog -g GOAL FILE ... runs a goal and halts.
  • -m 8 stralog gives it an 8 MiB arena, about 7 MiB of heap.

The top level and read/1 read through a line editor: Backspace, Ctrl-U, ↑ and ↓ for earlier lines, and Ctrl-D, which ends [user]. After an answer that may have others, ; asks for the next one.

The examples are on the disk under /stralog, and [queens] finds them there.

The conformance vectors are ISO's and Szabó and Szeredi's, by way of Logtalk's tests (Apache-2.0); 584 of the 596 that fit Stralog pass. The README lists the twelve that do not.

The languageTerms and syntax

A Prolog program, a query and the data it works on are all terms. There are four kinds: atoms, numbers, variables and compound terms. Lists and strings are compound terms written another way. This is how Stralog reads and writes each.

Atoms

An atom is a name. It is written in one of four ways:

  • a letter word: a lower-case letter, then letters, digits and _: foo, hello_world, x2;
  • a symbol word: a run of + - * / \ ^ < > = ~ : . ? @ # & $: =.., -->, \==. A clause ends with . followed by layout, so X = +. does not end: +. is one atom;
  • a solo atom: !, ;, [] and {};
  • quoted: any text in single quotes, 'hello world', 'Abc', ''. A quote inside is doubled ('don''t') or escaped ('don\'t').

Escapes, in quoted atoms and in strings: \n newline, \t tab, \r, \a, \b, \f, \v, \0, \e escape, \s space, \\, \', \", \`, \x41\ (hexadecimal) and \101\ (octal). A backslash at the end of a line continues the text on the next. Any other escape is a syntax error.

An atom's text is bytes: what the source had, UTF-8 if it was. atom_length/2 counts bytes. A name has at most 1000 bytes. Atoms are never collected; there are 80 KiB of them. [] is an ordinary atom, the same as '[]', as in ISO (in SWI-Prolog 7 it is a special constant).

Numbers

Stralog's numbers are integers of 61 bits, from -260 to 260-1 (-1152921504606846976 to 1152921504606846975). There are no floats, so 1.5 and 1.0e10 are syntax errors, and no big integers: arithmetic beyond 61 bits raises evaluation_error(int_overflow).

  • 42, 007: decimal;
  • 0x1F, 0o17, 0b101: hexadecimal, octal, binary (the prefix in lower case);
  • 0'a: the code of a character, 97; 0'\n is 10, 0' 32, and 0''' or 0'' 39 (a quote).

A - directly before a number makes it negative: -1 is the integer -1. With layout between them, or in parentheses, it is the operator: - 1 and -(1) are the compound term -(1), and integer(- 1) fails. SWI-Prolog reads - 1 as the integer. The smallest integer cannot be written as one number (its digits alone are too large); X is -1152921504606846975 - 1 makes it.

Variables

A variable starts with a capital letter or _: X, Result, _Acc. _ alone is the anonymous variable: each _ is a different one. The scope of a variable is its clause, or its query; a clause or query read has at most 64 named variables. In answers, the top level writes a query's variables by their names and the other variables as _A, _B, ...; write/1 writes them as _ and a number.

Compound terms

A compound term is a name and arguments: point(1, 2), f(g(X), [a]). There is no space between the name and ( (f (a) is a syntax error). Its name is an atom, its arity the number of arguments, at most 255; point/2 is the usual way to write a name and an arity together, and the reference uses it for predicates. Arguments are terms of priority 999 at most: an argument with an operator above that (:-, ;, ->, the comma) goes in parentheses, f((a :- b)). Operators make compound terms too: 1+2 is +(1, 2), and {a, b} is '{}'((a, b)).

Lists

A list is [], the empty list, or a cell '.'(Head, Tail) whose tail is a list. It is written in brackets: [a, b, c] is '.'(a, '.'(b, '.'(c, []))), and [H|T] is a cell with head H and tail T; [a, b|T] has two elements and then T. A partial list ends in a variable, [a|_]; a proper list ends in []. The cell's name is '.', as in ISO (SWI-Prolog 7 uses '[|]').

Strings

Text in double quotes is a list of codes: "abc" is [97,98,99], and "" is []. Back quotes read the same: `abc` is [97,98,99]. Stralog has no string type and no double_quotes flag (there are no flags: no set_prolog_flag/2); it always reads double quotes as ISO's double_quotes flag set to codes would. This suits DCGs: phrase(greeting, "hello"). The answers show code lists as lists of numbers; format("~s", [Codes]) and atom_codes/2 turn them back into text.

Operators

An operator is an atom that can be written before (prefix), between (infix) or after (postfix) its arguments. Each has a priority from 1 to 1200, and a type that says where its arguments go and how it groups with itself: f is the operator, x an argument of lower priority, y one of lower or equal priority. So yfx groups to the left (1-2-3 is (1-2)-3), xfy to the right (a,b,c is a,(b,c)), and xfx not at all (1 = 2 = 3 is a syntax error, and so is 2**3**4). A term written with an operator has the operator's priority; a term in parentheses, or that is not an operator term, has priority 0. op/3 defines more operators, and changes or removes these:

An atom that is an operator can still be an atom: X = (+), f(-, +). writeq/1 puts such an atom in parentheses as an argument, and writes - (1) with its space so that it reads back as the compound.

Comments and clauses

% starts a comment to the end of the line; /* ... */ is a comment that may span lines. A clause, a query or a term read by read/1 ends with . followed by layout or %. In a file, :- Goal. is a directive (run as the file is consulted), Head :- Body. a rule, Head --> Body. a grammar rule, and anything else a fact.

The referenceReading the entries

Each entry gives the predicate's template, what it does, the errors it raises, where it differs from ISO Prolog or SWI-Prolog, and examples.

Templates and modes

A template, like atom_length(+Atom, ?Length), names each argument and says how it must be given with a mode before it:

  • +: given (bound) when it is called; a variable there is usually an instantiation_error;
  • -: an output, normally an unbound variable, that the predicate binds (if it is bound, the result is unified with it);
  • ?: either;
  • @: any term, which the predicate does not bind;
  • :: a goal, or a closure that gets more arguments, which the predicate calls.

A predicate that can be used in several directions has a template for each. The argument's name says what it must be: Atom, List, Goal and so on; Name/Arity is a predicate indicator. Unless an entry says that a predicate gives several answers on backtracking, it succeeds at most once.

Errors

Errors are thrown as ISO error terms, error(Formal, Context), which catch/3 catches. The entries list the formal terms: instantiation_error (an argument is not bound enough), type_error(Type, Culprit) (it is the wrong kind of term), domain_error(Domain, Culprit) (the right kind, but out of range), existence_error(procedure, Name/Arity) (a call to an unknown predicate), permission_error(Action, Type, Culprit), representation_error(What), evaluation_error(What), resource_error(What) and syntax_error(Message). The context is left unbound by the builtins the engine runs, and is the predicate's Name/Arity for those written in Prolog (boot.pl).

At the top level an uncaught error prints as Error: and the formal term; Error: unknown procedure Name/Arity for a call to a predicate that does not exist; Syntax error: and the message for a query that could not be read; and Error: uncaught and the ball for anything thrown that is not an error/2 term. A predicate that fails where ISO raises an error says so under "differs".

The examples

The examples are top-level sessions, as Stralog prints them. ?- is the prompt; a line that ends in ; is an answer after which ; was typed to ask for the next, and a . alone on a line is the end of an answer that might have had others, after which Enter was pressed. A line shaded as input was typed (for read/1 and get_char/1). Try asks the query in the playground, where earlier queries' clauses and operators are still there. Every example on this page is run by make test (the test stralog-ref), in one session, in the order of the page, and its output must be what is shown here.
